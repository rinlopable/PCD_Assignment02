# PCD_Assignment02

This repository contains my second Digital Image Processing assignment about low-contrast image enhancement.

In this assignment, I use four original images as reference images. The contrast of each image is reduced to create low-contrast test images, then Contrast Stretching is applied to enhance them.

The results are compared visually and using PSNR (Peak Signal-to-Noise Ratio) before and after enhancement.

## Method

- Contrast Stretching

## Evaluation

- Visual comparison
- PSNR comparison
